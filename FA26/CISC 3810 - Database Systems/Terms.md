## About: Data
1) Raw Data/Unstructured data:
	- Not yet processed to reveal meaning of end user.
	- Building blocks of "information"
2) Structured Data:
	- Results from formatting unstructured data to facilitate storage, use, and generation of information.
3) Semi-structured Data:
	- Processed to some extent. Most data is semi-structured. 
4) Information: 
	- Processed raw data
	- Reveal meaning of end user.
5) Database:
	- Structure for data.
	- Stores raw facts, specified to a topic.
6) Metadata:
	- Data about data
	- Describes data characteristics and relationships.
7) Database Management Systems (DBMS)
	- Collects, manages, and controls the data stored in a database.
8) Field: 
	- A group of characters that has a specific meaning. Used to define and store data
9) Record:
	- A logically connected set of one or more fields that describes a person, place, or thing.
	
## Types Of Databases
1) Single User Database:
	- Single-user database (usually on a personal computer.)
2) Multiuser Database:
	- Workgroup databases, Enterprise databases. Each supporting larger groups of users.
3) Centralized Database:
	- Data located at a single site.
4) Distributed Database: 
	- Data located at multiple sites.
5) Cloud Database:
	- Data stored online for access over the web.
6) General-purpose database: 
	- contains data focused on specific subject areas.
7) Operational database:
	- Designed to support a group's day-to-day operations.
8) Analytical database:
	- Stores historical data and business metrics used exclusively for tactical or strategic decision making.

## Other
1) Extensible Markup Language (XML):
	- Represents and manipulates data elements in textual format.
